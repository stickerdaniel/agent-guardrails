# Notices for the Gate X experiment

Everything under `experiments/native-distribution/` is an unmerged,
experimental verification spike. This file covers the material in it that
comes from other projects.

## no-ai-marks

`rust/src/main.rs` is a Rust port of `agent_guardrails/hidden.py`, which is
`no_ai_marks/chars.py` from
[mishan/no-ai-marks](https://github.com/mishan/no-ai-marks) at commit
`747c07a76d2ad6471fa73779dc8de97fbcb4aefe`, together with parts of this
repository's `rules.py`, `report.py` and `gitdata.py`.
`bench/hidden_tuned.py` is a modified copy of that same `hidden.py`; its

## Statically linked runtime

The executables in `bin/` also contain, statically linked, the Rust 1.97.1
standard library, the musl libc and crt objects that toolchain ships for
`*-unknown-linux-musl`, and LLVM libunwind. Their license texts are not
reproduced here yet. Collecting them is a precondition of any release built
this way; it is not needed for this unmerged experiment.
