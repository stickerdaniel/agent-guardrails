# Native distribution spike (Gate X)

EXPERIMENTAL. This directory exists on one verification pull request that is
closed unmerged. It is not the required check, it enforces no policy, and
nothing here is a release or a complete action. The required
`check-bot-coauthors` job still runs the trusted Python action from `main`
and must admit this tree like any other.

Gate X asks one question before a full native port: can a Rust binary ship
inside this repository, be proven to come from its source, reach the runner,
and start faster than the Python check without a new trust path? It answers
with the hidden-Unicode drive only. There is no Git acquisition, no event
parsing, no identity or attribution check and no process supervisor here.

## What is committed

| Path | What it is |
| --- | --- |
| `bin/linux-x64/agent-guardrails.gz`, `bin/linux-arm64/agent-guardrails.gz` | Genuine gzip streams, each holding one statically linked ELF. The required checker logs them as unscanned binary; their correspondence to the source is proven by the `reproduce` jobs below, not by that checker. |
| `rust/` | The drive: `src/main.rs`, and `src/tables.rs`, ASCII Rust source generated by `tools/gen_tables.py`. No binary table file exists. |
| `build/` | `recipe.json` (the pinned inputs), `build-in-image.sh` (runs inside the pinned image), `reproduce.py` (two fresh builds, then byte comparison). |
| `launch.sh`, `action.yml` | The experimental action: platform selection, private extraction, execution, cleanup. |
| `tools/` | `gen_tables.py`, `verify_artifacts.py` (envelope and ELF checks), `baseline.py` (the pinned Python baseline). |
| `bench/` | `contract.json` (the predeclared measurement), `measure.py`, `spawn.py`, `py_driver.py`, `hidden_tuned.py`, `gen_corpora.py`, `capture.py`. |
| `tests/` | Launcher and artifact tests; `run_all.py` fails on any skip. |
| `ci/transfer-template.yml` | The remote-`uses` measurement, for the maintainer to fill in (see below). |

The benchmark corpora are generated, never committed: several contain hidden
Unicode on purpose, and `gen_corpora.py` writes every such character as an
escape and checks each capture against its pinned hash.

## Build and reproduce

`build/recipe.json` pins, per architecture, the `rust:1.97.1-alpine3.23`
image by digest, the exact `rustc` commit, `cc` (GCC 15.2.0) driving GNU ld
2.45.1 with the toolchain's self-contained musl objects, `panic = "unwind"`,
fat LTO, one codegen unit, stripped symbols, fixed path remapping, a fixed
`SOURCE_DATE_EPOCH` unrelated to any commit, and BusyBox 1.37.0 `gzip -9 -c`
from stdin. Builds run with `--network none` and
`cargo build --frozen --offline`; the crate has no dependencies.

```bash
python3 -I -B experiments/native-distribution/build/reproduce.py --arch arm64 --work "$(mktemp -d)"
```

Two builds from unrelated host and container paths must match each other,
and the committed `.gz` must equal a fresh compression byte for byte and
decompress to the fresh ELF byte for byte. `tools/verify_artifacts.py` also
requires the canonical envelope (one member, header `1f8b0800000000000203`,
nothing after the trailer) and a static ELF for the named machine.

## The launcher

`launch.sh` requires `RUNNER_OS=Linux`, a Linux kernel, and `uname -m` of
`x86_64` or `aarch64`, which select `bin/linux-x64` or `bin/linux-arm64`.
It creates a fresh directory with `mktemp -d` under `RUNNER_TEMP` (umask
077), decompresses into a new file there, and runs the binary only if gzip
exited 0: a stream with a bad CRC is never executed, although gzip already
wrote all of it. It refuses a noexec `RUNNER_TEMP` before trying to run.

It never `exec`s the binary, so its cleanup always runs and removes only the
directory it created. The binary's exit status is the launcher's. On INT,
TERM or HUP it sends TERM to the running child (a background child starts
with INT ignored), waits for it, removes the directory, and dies of the
caught signal. SIGKILL cannot be caught; after it the directory stays until
the runner clears `RUNNER_TEMP`. A signal inside `mktemp` itself can leave
that one empty directory.

The gzip member policy (one member, nothing appended) is enforced by CI on
the committed bytes, not by the launcher: GNU gzip accepts concatenated
members.

## Measurement

`bench/contract.json` was written and hashed before any candidate timing. It
fixes seven paired rounds per architecture after one warmup round, a seeded
order, twelve cases (empty, the typical 889-line PR, 10 MiB ASCII,
Unicode Markdown and CJK, sparse and dense findings, bidi, ideographic
spaces, a minified 3.8 MB line, a findings-limit stop), and the decision
rules: no small-input median regression beyond max(5 ms, 5%), and at least
20% and 100 ms median saving on 10 MiB ASCII and Unicode Markdown, each
checked against the paired per-round interval.

The decision candidate is `rust-packaged`: the real launcher, extraction and
cleanup included. `rust-extracted` and `gunzip-only` are components and are
never summed into it. `python-faithful` (CPython 3.14, Unicode 16) is the
parity oracle; `python-tuned` is the named optimized Python; the runner's
Python 3.12 is a control only. Peak RSS cannot read below the spawner's own,
recorded every round as `rss_floor_kib`.

```bash
python3 -I -B experiments/native-distribution/bench/gen_corpora.py --out "$RUNNER_TEMP/corpora"
python3.14 -I -B experiments/native-distribution/bench/measure.py --baseline <40382e2 checkout> \
  --corpora "$RUNNER_TEMP/corpora" --python314 "$(command -v python3.14)" --label local --out result.json
```

## Transfer

What the runner spends downloading and preparing the action can only be

maintainer adds it in a second commit: a workflow cannot name the commit
that contains it.

## Provenance

Derived from the Gate X benchmark prototype, with these changes:
`rust/src/main.rs` keeps only `drive`, writes and flushes each report line
on its own, refuses a malformed or oversized capture without panicking, and
ends a panic in one constant line and exit status 1 under `panic = "unwind"`
(the prototype used `abort`). `rust/src/tables.rs` carries the prototype's
`stage2.bin` as a decimal array; `tools/gen_tables.py --check` proves the
property values and the second stage equal the prototype's recorded hashes.
`bench/gen_corpora.py` writes the prototype's literal characters as escapes
and reproduces its corpora byte for byte. `bench/capture.py` and
`bench/hidden_tuned.py` are unchanged copies. Third-party notices are in
`NOTICE.md`.
